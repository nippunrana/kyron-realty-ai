# Project Context: Agora Realty AI

## Overview
Agora Realty AI is a modern real estate intelligence platform integrating AI capabilities for property analytics, customer interaction, and workflow automation.

## Technology Stack
- **Architecture**: Full-Stack
- **Frontend / Backend**: Node.js & React / TypeScript
- **Repository**: [nippunrana/agora-realty-ai](https://github.com/nippunrana/agora-realty-ai)

## Guidelines & Best Practices
- Keep components modular and maintainable.
- Never commit secret keys or `.env` files.
- Follow clean coding practices with clear commit messages.
