# Hackathon Submission: Light/Bright Mode 4-Slide Deck & Text

## 1. Problem Description (46 Words)
> Over 60% of high-ticket real estate and rental calls go to voicemail because agents are occupied. Inbound leads decay within 5 minutes, costing agencies billions in lost commissions. Meanwhile, rigid automated voice bots fail when callers interrupt, change requirements mid-call, or ask to negotiate rental pricing.

---

## 2. Proposed Solution / Idea Overview (131 Words)
> AgoraRealty AI is an adaptive, real-time voice sales agent that automates property qualification and rental negotiations 24/7 without rigid scripts. Built on the Agora Agents SDK and SD-RTN, it delivers sub-500ms voice turn-taking with instant interruption handling.
>
> Our approach features a dual-engine architecture: a High-Precision Modular pipeline (.with_stt + .with_llm + .with_tts) for live MLS database queries and lease math, alongside an Ultra-Realistic Multimodal pipeline (.with_mllm) for empathetic objection handling.
>
> What makes it unique is our Give-Get Negotiation Engine: rather than offering flat discounts, the agent grants concessions (like rent reductions or waived parking) only in exchange for high-value commitments (such as 18-month leases or immediate move-ins) within strict margin guardrails. When high-value buyers emerge, it seamlessly bridges human brokers into the live Agora channel with an instant context briefing HUD.
